# Knot — 社内ワークスペース

Notion の進化版イメージで、**タスク管理 / スケジュール管理 / プロンプト補完 / 画面内AI** をひとつに結ぶ個人用システムです。

## 機能

- **ログイン**: 本人のみ利用の前提。初回にパスワード設定、以降はログイン
- **タスク**: カンバン / リスト、優先度・期限・担当・タグ
- **スケジュール**: 月次カレンダー、タスク連携
- **プロンプト補完**: テンプレ・変数埋め込み・スラッシュ補完 → **画面内でAI実行**
- **AI**: 固定プロンプト＋システムプロンプトを毎回付与してチャット実行
- **設定**: OpenAI互換APIキー / モデル / 固定プロンプト管理

APIキー未設定時はデモAIでUIを確認できます（設定で切替可）。データは `localStorage` に保存。

## 起動

```bash
cd company-os
npm install
npm run dev
```
